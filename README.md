# Catalogo Asta Torre Nera

Pagina pubblica del catalogo d'asta del Mercatino Torre Nera, servita da
GitHub Pages: <https://lanadelrekt.github.io/asta-torre-nera/>

**Questo repository non si modifica a mano.** `index.html` e' generato dal
motore che sta nel repo privato `Slide-Asta-Matta`, a partire dai record
Airtable e dalle foto dei venditori, e viene sovrascritto a ogni pubblicazione
con `python pubblica.py`.

La pagina e' un unico file autosufficiente: le foto sono incorporate come
data URI, perche' gli URL degli allegati Airtable scadono dopo qualche ora.
Non contiene dati personali dei venditori ne' credenziali.
